
## WHMCS LXD对接插件配置指南

### 1. 插件安装

- **插件地址**: [ccmaoxiong/lxd/whmcs](https://github.com/ccmaoxiong/lxd/tree/main/Fmis/whmcs/lxdapiserver)
- **安装路径**: 将插件上传至服务器的 `/modules/servers` 目录。

### 2. 接口配置

导航至 `系统设置 > 产品/服务 > 服务器`，添加新服务器并填写以下信息：

- **名称**: 按需填写
- **主机名**: 填写后端服务的 IP 或域名
- **最大账户数**: 按需填写
- **模块**: `WHMCS-LXD对接插件 by ccmaoxiong`
- **访问哈希**: 填写后端 Hash
- **安全**: 开启SSL
- **端口**: 填写后端服务端口

### 3. 产品配置

1.  导航至 `系统设置 > 产品/服务`，选择一个产品进行编辑或创建新产品。
2.  在 **模块设置** 标签页中，选择 `WHMCS-LXD对接插件 by ccmaoxiong`。

### 4. 可配置选项组

导航至 `系统设置 > 其他 > 可配置选项组`，创建选项组并参考下表设置配置项。

**说明**: `参数名|显示名` 的格式用于区分内部参数和前台显示名称，`参数值|显示值` 同理。

| 配置选项 | 选项值 | 单位 |
|:---|:---|:---|
| `cpus\|CPU` | `1\|1核` | 核 |
| `memory\|内存` | `512\|512MB` | MB |
| `disk\|硬盘` | `1024\|1024MB` | MB |
| `traffic_limit\|月流量限制` | `100\|100G` | G |
| `ingress\|上行带宽` | `100\|100Mbps` | Mbit |
| `egress\|下行带宽` | `100\|100Mbps` | Mbit |
| `image\|操作系统` | `ubuntu2404\|Ubuntu24 AMD64` | 镜像 |
| `ipv4_pool_limit\|独立IPv4数量` | `1\|1个` | 个 |
| `ipv6_pool_limit\|独立IPv6数量` | `1\|1个` | 个 |
| `ipv4_mapping_limit\|IPv4转发规则数量` | `1\|1条` | 条 |
| `ipv6_mapping_limit\|IPv6转发规则数量` | `1\|1条` | 条 |
| `reverse_proxy_limit\|反代理规则数量` | `1\|1条` | 条 |
