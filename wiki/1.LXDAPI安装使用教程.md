## 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Debian、Ubuntu |
| LXD版本 | 6.x |
| 架构 | amd64 / arm64 |
| 权限 | root |

> 推荐：使用 [bin456789/reinstall](https://github.com/bin456789/reinstall) DD脚本安装纯净 Debian 13

## 前置准备：安装基础软件包

```bash
apt update && apt install sudo wget curl nftables -y
```

## 环境准备：安装 LXD

```bash
bash <(curl -Ls https://raw.githubusercontent.com/xkatld/lxdapi-web-server/main-stable/Shell/lxd_install.sh)
```

脚本流程：
- 检测系统 Debian/Ubuntu
- 安装 snapd、core、LXD 6.x
- 配置 lxcfs.flags、daemon.debug
- 初始化 lxdbr0 网络，可选 IPv4/IPv6

网络配置选项：
- IPv4：默认 10.66.0.1/16，NAT 开启
- IPv6：默认 fd66:6666::1/64，NAT 开启

## 主流程

### 1.ZFS 安装

```bash
bash <(curl -Ls https://raw.githubusercontent.com/xkatld/lxdapi-web-server/main-stable/Shell/lxdapi_zfsinstall.sh)
```

仅支持 Debian，预编译内核模块：

| Debian版本 | 架构 | 内核版本 | ZFS版本 |
|------------|------|----------|---------|
| 11 | amd64 | 5.10.0-43-amd64 | 2.1.15 |
| 11 | arm64 | 5.10.0-43-arm64 | 2.1.15 |
| 12 | amd64 | 6.1.0-48-amd64 | 2.2.7 |
| 12 | arm64 | 6.1.0-48-arm64 | 2.2.7 |
| 13 | amd64 | 6.12.88+deb13-amd64 | 2.3.0 |
| 13 | arm64 | 6.12.88+deb13-arm64 | 2.3.0 |

流程：
- 检测系统架构
- 检测内核版本，不匹配则自动安装指定内核
- 清理旧内核文件、更新 grub
- 需手动 reboot 后重新运行脚本
- 下载预编译 ZFS 模块部署至 `/lib/modules/{kernel}/updates/dkms/`
- 安装 zfsutils-linux

### 2.安装 LXDAPI

```bash
bash <(curl -Ls https://raw.githubusercontent.com/xkatld/lxdapi-web-server/main-stable/Shell/lxdapi_install.sh)
```

#### 步骤 1/5：基础软件包

安装 unzip、e2fsprogs、bc、fdisk、parted

#### 步骤 2/5：下载

| 交互项 | 默认值 |
|--------|--------|
| 下载源 | github / gitee |
| 安装版本 | 最新版本号 |

自动检测架构下载 `lxdapi-linux-{arch}.tar.gz`，解压至 `/opt/lxdapi`

#### 步骤 3/5：配置

| 交互项 | 默认值 | 说明 |
|--------|--------|------|
| 服务端口 | 8443 | 监听端口 |
| API密钥 | 随机生成 | 16字节hex，财务对接用 |
| 管理员用户 | admin | 后台登录用户名 |
| 管理员密码 | 随机生成 | 8字节hex |
| 流量采集间隔 | 20 | 秒 |
| 流量批量更新 | 10 | 条数 |
| 任务清理天数 | 7 | 已完成任务自动删除 |
| Nginx插件 | y | 启用则自动安装nginx |

固定配置：
- 任务队列：Memory
- 数据库：SQLite（路径：`/opt/lxdapi/lxdapi.db`）
- Session密钥：随机生成

#### 步骤 4/5：启动服务

创建 systemd 服务 `/etc/systemd/system/lxdapi.service`：

```
WorkingDirectory=/opt/lxdapi
ExecStart=/opt/lxdapi/lxdapi-{arch}
Restart=always
RestartSec=5
```

自动 enable + start

#### 步骤 5/5：完成

输出安装信息：
```
服务端口: 8443
API密钥: xxxxxxxxxxxxxxxx
管理员用户: admin
管理员密码: xxxxxxxx
任务队列: Memory
数据库类型: SQLite
流量采集间隔: 20s
```

### 3.存储池管理

```bash
bash <(curl -Ls https://raw.githubusercontent.com/xkatld/lxdapi-web-server/main-stable/Shell/storage_pool.sh)
```

菜单选项：
- [1] 创建存储池
- [2] 删除存储池
- [3] 列出存储池

#### 创建存储池

驱动选择：
- ZFS：自动安装 zfsutils-linux、zfs-dkms（Debian）或 zfsutils-linux（Ubuntu），启用 LXD 外部ZFS
- Btrfs：安装 btrfs-progs

存储方式：
- 自动创建：根据剩余空间计算默认大小（可用空间-5GB，最小10GB）
- 独立磁盘：指定磁盘设备如 sdb，自动 wipe

存储池名称：自动检测避免冲突，默认 `default` 或 `pool1/pool2...`

## 其他说明

### 1.更新 LXDAPI

```bash
bash <(curl -Ls https://raw.githubusercontent.com/xkatld/lxdapi-web-server/main-stable/Shell/lxdapi_update.sh)
```

流程：
- 检测架构、当前版本
- 选择下载源、更新版本
- 停止服务
- 备份至 `/opt/lxdapi/backup/{时间}/`：config.yaml、二进制、证书、数据库
- 下载新版本解压替换
- 启动服务
- 失败时自动回滚

### 2.NAT配置

```bash
ip ad
```

示例输出：

## 独立IP网络配置

### IPv4 池管理

添加方式：IP范围

| 字段 | 示例 |
|------|------|
| 起始IP | 173.208.194.83 |
| 结束IP | 173.208.194.86 |
| 网卡接口 | enp2s0 |

生成 4 个独立 IPv4：173.208.194.83 ~ 173.208.194.86

### IPv6 池管理

添加方式：起始IPv6 + 数量

| 字段 | 示例 |
|------|------|
| 起始IPv6 | 2604:4300:a:33a::1000 |
| 数量 | 100 |
| 网卡接口 | enp2s0 |

生成 100 个独立 IPv6：2604:4300:a:33a::1000 ~ 2604:4300:a:33a::1063
