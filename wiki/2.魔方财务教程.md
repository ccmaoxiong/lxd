## 1. 插件安装

- **插件选择**:
  [xkatld/lxdapi-web-server/zjmf](https://github.com/xkatld/lxdapi-web-server/tree/main-stable/Fmis/zjmf/lxdapiserver)

- **安装位置**:
  将插件文件上传至服务器的 `/public/plugins/servers` 目录。

## 2. 接口配置

进入 **设置 > 通用接口 > 接口** 页面，进行如下配置：

- **名称**: 按需填写
- **IP地址**: 填写后端服务的 IP 或域名
- **服务器模块**: 选择 `魔方财务-LXD对接插件 by xkatld`
- **接口容量**: 按需填写
- **端口**: 填写后端服务端口
- **secure**: 启用 SSL
- **Hash**: 填写后端 Hash

## 3. 产品配置

编辑商品，在 **自动开通** 选项中，设置 **开通方式** 为 `自动化接口`，并选择 **接口分组** 为 `魔方财务-LXD对接插件 by xkatld`。

## 4. 自定义产品配置

进入 **编辑商品 > 产品配置** 页面，参考下表设置配置选项：

| 配置选项名称         | 配置项类型         | 子项名称                      | 单位 |
|:---------------------|:-------------------|:------------------------------|:-----|
| cpus\|CPU             | cpu核心单选        | 1\|1核                        | 核   |
| memory\|内存          | 内存单选           | 512\|512MB                    | MB   |
| disk\|硬盘            | 系统盘容量单选     | 1024\|1024MB                  | MB   |
| traffic_limit\|月流量限制 | 任意数量单选       | 100\|100G                     | G    |
| ingress\|上行带宽     | 带宽单选           | 100\|100Mbps                  | Mbit |
| egress\|下行带宽      | 带宽单选           | 100\|100Mbps                  | Mbit |
| image\|操作系统       | 操作系统           | ubuntu2404\|Ubuntu^ubuntu24 amd64 | 魔方固定格式 |
| ipv4_pool_limit\|独立IPv4数量 | 任意数量单选       | 1\|1个                        | 个   |
| ipv6_pool_limit\|独立IPv6数量 | 任意数量单选       | 1\|1个                        | 个   |
| ipv4_mapping_limit\|IPv4转发规则数量 | 任意数量单选 | 1\|1条                        | 条   |
| ipv6_mapping_limit\|IPv6转发规则数量 | 任意数量单选 | 1\|1条                        | 条   |
| reverse_proxy_limit\|反代理规则数量 | 任意数量单选 | 1\|1条                        | 条   |
