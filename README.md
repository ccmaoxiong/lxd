## 项目特色

- 高性能 Go 后端服务
- 完整的容器管理功能
- IPv4 与 IPv6 双栈支持
- NAT 端口映射与转发
- 流量监控与限制统计
- WebSocket 控制台与 VNC 支持
- 多级权限与安全认证
- 品牌自定义与插件化架构
- 多数据库支持 SQLite MySQL PostgreSQL
- 异步任务队列与 RESTful API

## 已实现功能

- 容器生命周期管理
- IPv4 与 IPv6 地址池
- NAT 端口转发与规则映射
- 流量监控限制与阈值告警
- WebSocket VNC 控制台
- 三级权限系统与用户管理
- 异步任务队列
- Nginx 反向代理配置
- OpenGFW 防火墙规则
- 镜像模板管理
- 多数据库引擎兼容 SQLite MySQL PostgreSQL
- 管理后台与容器独立面板
